# Changelog

All notable changes to this project will be documented in this file.

## 0.0.1

- Added a VS Code sidebar search view with an extra result-filter input.
- Added native quick-search fallback for environments where webviews are unavailable.
- Added match-case and whole-word options for filtering found results.
- Added replace support for the currently filtered result set.
- Added `ripgrep` search with a built-in JavaScript fallback.
