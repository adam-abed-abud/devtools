# Find and grep

VS Code search and replace with a second filter step.

## Usage

Open **Find and grep** in the Explorer sidebar, or run `Find and grep: Quick Search` from the Command Palette.

## Features

- Search a workspace or folder.
- Filter results by path or matching line.
- Replace only filtered results.

## Shortcut

- Windows/Linux: `Ctrl+Alt+F`
- macOS: `Cmd+Alt+F`
