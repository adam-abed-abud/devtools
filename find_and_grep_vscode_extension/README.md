# Find and grep

Find and replace for VS Code with an extra filter for narrowing search results.

## Usage

Open the **Explorer** sidebar and expand **Find and grep**.

If you do not see it:

1. Open the Command Palette with `Ctrl+Shift+P` / `Cmd+Shift+P`.
2. Run `View: Explorer`.
3. Look for **Find and grep** near the bottom of the Explorer sidebar.

You can also run `Find and grep: Quick Search` from the Command Palette.

## Features

- Search a workspace or selected folder.
- Filter results by file path or matching line.
- Use match-case and whole-word options for the filter.
- Replace only the filtered results.

## Keyboard Shortcut

- Windows/Linux: `Ctrl+Alt+F`
- macOS: `Cmd+Alt+F`
